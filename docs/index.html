Un CV a medida para cada oferta, sin rehacerlo desde cero.

ApplyKit es un workspace para postular con tu agente de IA. Convierte tus CVs, contratos y certificados en una memoria profesional reutilizable, y a partir de ella genera CVs, cartas y PDFs enfocados en cada puesto, con un panel para seguir tus postulaciones.

De tus documentos a un CV enfocado

Enviar el mismo CV genérico a todas las ofertas no funciona. ApplyKit separa tu experiencia real de cada versión que envías.

Reúne tu evidencia

Guarda CVs antiguos, contratos, certificados y títulos en sources/.

Crea tu memoria profesional

Tu agente extrae fechas, roles, logros y tecnologías a master-info/, marcando lo dudoso en lugar de inventarlo.

Genera un CV por oferta

Pega la oferta y el agente prepara el CV, las notas de estrategia y la carta. Revisas la vista previa y exportas el PDF.

Qué incluye

📄

Plantillas por rol

Android, Backend, Fullstack y ATS. Datos en JSON, vista previa en HTML y PDF A4 listo para enviar.

🇪🇺

Estándar europeo

Sin foto ni datos sensibles, una sola columna legible por ATS, idiomas con nivel MCER y fechas MM/AAAA.

✅

Validación automática

Avisa de fechas mal formateadas, perfiles demasiado largos, CVs de más de 2 páginas o páginas medio vacías.

✉️

Cartas de presentación

Plantilla de una página generada desde datos estructurados, con la misma coherencia que tu CV.

📋

Panel de postulaciones

Empresa, rol, estado, fecha, notas y PDF de cada postulación en un panel local.

🔒

Tus datos se quedan contigo

Todo funciona en local. El .gitignore impide publicar tus documentos, tu memoria y tus postulaciones.

¿Es para ti?

Úsalo si…

  • Postulas a muchas ofertas y quieres adaptar cada CV sin empezar de cero.
  • Tu perfil sirve para varios roles (por ejemplo mobile, backend o sistemas).
  • Ya trabajas con un agente de IA como Claude Code, Cursor o Codex.
  • Postulas en Europa y quieres un formato que pase los filtros ATS.

Quizá no lo necesites si…

  • Buscas un editor visual de CVs con plantillas de diseño.
  • Solo vas a enviar uno o dos CVs.
  • Prefieres no usar la terminal ni un agente de IA.

Empieza en 4 pasos

Necesitas Node.js 18 o superior y un agente de IA.

1. Clona e instala

Instala el generador y el navegador para exportar PDFs.

git clone https://github.com/yahyrparedes/ApplyKit.git cd ApplyKit/generator npm install npx playwright install chromium

2. Añade tus documentos

Copia tus CVs y evidencias. Después pide a tu agente que construya tu memoria profesional con el primer prompt de PROMPTS.md.

# old CVs sources/cv/ # contracts, certificates, degrees… sources/supporting-documents/

3. Crea una postulación

Pega la oferta a tu agente, o crea la carpeta tú mismo y abre la vista previa.

npm run new -- --role android --company acme --title android-developer --template android npm run start # http://127.0.0.1:4173

4. Valida y exporta

Comprueba el formato europeo y genera el PDF con el nombre listo para enviar.

npm run validate -- --app acme-android-developer npm run pdf -- --template android --slug acme-android-developer \ --path /applications/android/acme-android-developer/cv-data.json # → output/pdf/acme-android-developer/Alex-Developer-CV-Android-Developer.pdf

Hecho para trabajar con tu agente

AGENTS.md le dice a tu agente qué leer, cómo crear cada postulación y, sobre todo, que no invente fechas, títulos ni tecnologías.
